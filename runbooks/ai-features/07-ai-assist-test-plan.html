F

Accuracy guardrails

A confident wrong answer is worse than no answer — but a correct refusal that sounds apologetic still costs you the room. These check both: the agent must never invent, and never describe the product by what it lacks.

F1Entity that doesn't exist — must not invent
كم عدد الشكاوى المسجلة هذا العام؟

Expect

One short clause that complaints aren't among these records, then an offer to look in tasks/decisions/agenda, then one question. Shape: الشكاوى لا تُدار ضمن سجلات الحوكمة هنا…

Fails if

It invents a number; says لا توجد شكاوى (implying the feature exists and is empty); mentions its own tools (لا تتوفر لدي أداة); or recites platform scope (المنصة تركز على… / هذا النظام مخصص لـ…).

F2A detail the records don't hold
ما ميزانية لجنة المراجعة لهذا العام بالريال؟

Expect

It searches first, then declines without inventing a figure, and offers to look for a decision or minutes that mention a budget.

Fails if

It invents a riyal amount, presents a decision title as if it were the budget, or opens with a scope disclaimer instead of the offer.

F4Empty ≠ non-existent — the distinction must hold
كم اجتماعاً لدينا في يناير 2027؟

Expect

Meetings are tracked, this period is simply empty — so it reports none scheduled for that month and offers to create one.

Fails if

It answers like F1 (لا تُدار هنا) — that would tell the user meetings aren't a feature.

F5Decline tone holds across different missing entities
اعرض لي طلبات الإجازات للموظفين1 ما إجمالي رواتب الموظفين هذا الشهر؟2

Expect

Both follow the F1 shape. Neither mentions tools, capabilities, or what the platform "focuses on".

Fails if

Either one lists the platform's covered areas — that reads as a limitation to a prospect.

F3Arabic only — no bilingual leakage
اعرض حالة جميع المهام مع أصحابها وتواريخ استحقاقها

Expect

Pure Arabic. Statuses as مكتملة / قيد التنفيذ / جديدة, priorities as عالية / حرجة.

S

Streaming protocol

The stream carries two vocabularies at once: the original frames (so nothing regresses) and the newer AG-UI run/step/tool events. Run these from a terminal. Get a token first:

TOKEN=$(curl -s -X POST http://localhost:8080/api/auth/login \ -H 'Content-Type: application/json' -H 'X-Tenant-Slug: acme' \ -d '{"identifier":"admin","password":"P@ssw0rd"}' | python3 -c 'import sys,json;print(json.load(sys.stdin)["accessToken"])')
S1Both vocabularies present, legacy frames intact
curl -sN -X POST http://localhost:8080/api/ai/assist/agent/stream \ -H "Authorization: Bearer $TOKEN" -H 'X-Tenant-Slug: acme' -H 'Content-Type: application/json' \ -d '{"query":"كم عدد المحاضر؟"}' | grep -o '"type": *"[A-Za-z_]*"' | sort | uniq -c

Expect

Legacy delta, tool, done all present, and RUN_STARTED, STEP_STARTED, TOOL_CALL_START, TOOL_CALL_END, RUN_FINISHED.

Fails if

Any legacy type is missing — an older client would break.

S2Ordering: RUN_STARTED first, done last
curl -sN … -d '{"query":"كم عدد المحاضر؟"}' | grep -o '"type": *"[A-Za-z_]*"' | sed -n '1p;$p'

Expect

First is RUN_STARTED; last is done (kept last so existing clients still detect completion).

Fails if

done is not the final frame.

S3Repeat tool calls are distinct (the dedup bug)
اعرض المحاضر أولاً، ثم بنود الأعمال، ثم المحاضر مرة أخرى للتأكيد.

Expect

In the panel, list minutes appears as two separate chips. Each TOOL_CALL_START carries its own toolCallId.

Fails if

Only one chip appears — that is the old name-based de-duplication returning.

S4Live activity label while a tool runs
اعرض المهام المتأخرة وحللها

Expect

The thinking line reads يشغّل list tasks… while the tool runs, then returns to جارٍ التفكير….

Fails if

It always shows the generic thinking text.

S5Stop keeps the partial answer — no false error
اكتب تقريراً مفصلاً وطويلاً جداً عن جميع الاجتماعات والقرارات والمهام.

Expect

Press إيقاف mid-answer. Text already streamed stays; a quiet تم إيقاف الإجابة note appears; the composer unlocks immediately.

Fails if

It shows a red network error, wipes the partial text, or the input stays disabled.

S6Cancelling logs no stack trace
docker logs magales-api --since 2m 2>&1 | grep -c "Unhandled exception"

Expect

0. A client disconnect is normal and is swallowed at DEBUG, not logged as an error.

Fails if

Any count above zero — every cancellation is polluting the logs.

S7Stopping actually stops the work
docker logs -f magales-ai-services # watch while you press إيقاف

Expect

Model activity ceases within a second or two of Stop — the request is not left running to completion.

Fails if

Tool calls keep appearing in the log after you stopped (tokens still burning).

I

Service integration

Three services and a proxy have to agree. These catch the failures that only appear when they are wired together.

I1All containers healthy
docker compose -f docker-compose.full.yml -p boardhub ps

Expect

Seven containers, all healthy: postgres, redis, minio, opensearch, api, ai-services, ui.

Fails if

Any is unhealthy or restarting.

I2Java proxy reaches ai-services
curl -s "http://localhost:8080/api/ai/assist/suggestions?scope_kind=&page=tasks&lang=ar" \ -H "Authorization: Bearer $TOKEN" -H 'X-Tenant-Slug: acme'

Expect

Four Arabic task chips. This proves browser → Java → Python end to end.

Fails if

An empty list — the proxy swallows upstream failures and returns [], so empty means ai-services is unreachable.

I3Tenant isolation is enforced
curl -s "http://localhost:8080/api/ai/assist/suggestions?page=tasks&lang=en" \ -H "Authorization: Bearer $TOKEN" -H 'X-Tenant-Slug: globex'

Expect

No acme data leaks into a globex-scoped response.

Fails if

Records from the other tenant appear — stop and treat as a security bug.

I4Agent counts match the database
docker exec magales-postgres sh -c \ 'psql -U "$POSTGRES_USER" -d "$POSTGRES_DB" -t -A -c "SELECT count(*) FROM agenda_items;"'

Expect

Matches what the agent answers for كم بند أعمال موجود؟. The escalation job can add items, so re-read both together.

Fails if

They disagree — the agent is not reading live data.

I5ai-services restart degrades gracefully
docker restart magales-ai-services # then ask a question immediately

Expect

The panel shows a clear failure message, not a spinner forever. Once healthy, the next question works with no page reload.

Fails if

It hangs indefinitely or needs a refresh to recover.

I6Conversation history survives a reload

Expect

Ask something, reload the browser, open 🕘 — the thread is listed and reopens with its messages (history is stored server-side, per user).

Fails if

The thread is gone, or reopening it shows an empty conversation.
